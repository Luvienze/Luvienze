## Things I've shipped

**Earthquake Risk Assessment Platform** — Production backend for a mobile app that evaluates structural earthquake risk using TBDY 2018 engineering models. Separated calculation engine processes 30+ parameters, generates a PDF, stores to S3, and returns results in under 1 second. Includes AFAD seismic data integration, cron-based notifications, and RevenueCat subscription/claim access control.

**Atoma** — Backend for a screen time and focus app. Built Socket.io architecture for real-time program access control signals, chained BullMQ event listeners for notification dispatch and reward delivery, and optimized leaderboard queries through indexing.

**Mygen (Onedio)** — Gamification backend with streak tracking, achievement rewards, and real-time leaderboards. Event-driven with BullMQ + Redis; push notifications via Firebase and OneSignal.

**Driver Management System (İETT)** — Internal web app for Istanbul's public transport authority. Built twice: Spring Boot backend first, then re-architected in ASP.NET Core Web API. Layered architecture, DTO pattern, SQL + Docker.
